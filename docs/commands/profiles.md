# profiles

List built-in audit profiles.

## Usage

```sh
repovista profiles [--json]
```

## Options

- `--json` emits profile data as JSON.

## Examples

```sh
repovista profiles
repovista profiles --json
repovista audit --audit-profile security
```

## Profiles

The current profiles are `quick`, `security`, `pr-review`, `release-readiness`, and `architecture`.
